# ADR-0003 — x402 as the machine payment rail; USDS as settlement

- **ADR**: 0003
- **Status**: proposed (ratify at Gate 0.4)
- **Date**: 2026-11-04
- **Deciders**: owner (regulator), executing agent (drafter)

## Context
x402 (HTTP 402 + stablecoins) crossed 100M agentic payments on Base (Chainalysis,
2026-06) and is packaged in Coinbase Agentic Wallets (2026-02). A2A has 150+ orgs and
enterprise production (LF, 2026-04). The estate already runs a 38-op DEX kernel with a
deterministic orderbook and live estate relay rails.

## Decision
Jobs API, RC² gateway, and SOL invoicing speak **x402** for external machine clients.
Settlement unit is **USDS** (escrow per job, roshpina-style 5% coordination fee).
A2A agent cards advertise the endpoints; MCP gains capability-scoped job tools.
L402-style metering is permitted where per-call x402 is too chatty.

## Consequences
External agents (Grok Bots, any MCP/A2A client) can become customers without the root
depending on them (Law 21). Stablecoin rails must inherit the G28 fail-closed cap
pattern (`maxFlow`, daily cap) at the treasury policy engine.

## Exit / Reversal
Rail is a persona-scoped capability; exit runbook: freeze rail keys, drain escrow,
disable capability, archive digests (≤ 1 working day, Law 21).
